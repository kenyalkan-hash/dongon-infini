# Donjon infini

Un jeu de survie à la Vampire Survivors, en 2D pixel art (Godot 4.7).

- **Jouer dans le navigateur** : https://kenyalkan-hash.github.io/dongon-infini/
- **Télécharger pour Windows** (PC, Legion Go...) : voir les [releases](../../releases/latest). Dézippe et lance `DonjonInfini.exe` ; ensuite le jeu se met à jour tout seul depuis l'écran titre.

Ce dépôt ne contient que les versions publiées. Le code source est développé dans un dépôt privé par l'équipe.
